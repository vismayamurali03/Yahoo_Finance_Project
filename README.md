# Cryptocurrency Price Analysis: Solana vs Cardano

## Project Overview
This project analyzes and compares two cryptocurrencies—**Solana (SOL-USD)** and **Cardano (ADA-USD)**—using historical market data from Yahoo Finance.

Python is used for data analysis, visualization, and exploring price trends and market behavior. The project aims to compare the historical performance of both cryptocurrencies and identify patterns in their prices and returns.

## Objectives
- Retrieve historical market data for Solana and Cardano from Yahoo Finance.
- Clean and prepare the data for analysis.
- Explore and compare historical closing prices.
- Analyze price trends and daily returns.
- Visualize market movements using charts.
- Explore machine-learning methods for estimating cryptocurrency prices, if implemented in the notebook.

## Cryptocurrencies Analyzed
| Cryptocurrency | Yahoo Finance Symbol |

| Solana | `SOL-USD` |

## How to Run
1. Clone or download this repository.
2. Install the required Python libraries:
   ```bash
   pip install pandas numpy matplotlib seaborn yfinance jupyter
   ```
3. Open the notebook:
   ```bash
   jupyter notebook cardano.ipynb
   ```
4. Run the notebook cells from top to bottom.
